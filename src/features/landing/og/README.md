Fonts for the Open Graph image (`src/app/(marketing)/opengraph-image.tsx`), read at build time by `next/og`, which needs static WOFF/TTF files and can't download them in CI.

- `plus-jakarta-sans-800.woff`: Plus Jakarta Sans ExtraBold, latin subset (Tokotype, SIL Open Font License 1.1).
- `instrument-serif-400-italic.woff`: Instrument Serif Italic, latin subset (Instrument, SIL Open Font License 1.1).

Both from Fontsource (`@fontsource/*` 5.2.5). The OFL allows bundling and redistribution with software.
