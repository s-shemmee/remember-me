# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Email [contact@shemme.codes](mailto:contact@shemme.codes) with a description, the affected version or commit, and steps to reproduce. Avoid including real user data or credentials in the report.

We will acknowledge reports and coordinate a fix and disclosure with the reporter. Please allow time for a fix before sharing vulnerability details publicly.

## Deployment and data

This repository is intended for self-hosting and development. Operators are responsible for securing their own Supabase instance, secrets, backups, email provider, and deployment. Never commit credentials or use production data in tests.
