# Code of Conduct

We want Remember Me to be a welcoming, respectful community for everyone.

This project follows the principles of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be considerate, use welcoming language, respect differing experiences, and accept constructive feedback. Harassment, discrimination, intimidation, and personal attacks are not acceptable.

Project maintainers may remove, edit, or reject comments, commits, code, issues, and other contributions that violate this code. They may temporarily or permanently exclude contributors for repeated or serious violations.

Report conduct concerns privately to [contact@shemme.codes](mailto:contact@shemme.codes). Please include enough context to understand what happened. Reports will be handled respectfully and kept confidential where possible.
